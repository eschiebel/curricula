# Curricula

A desktop application for managing educational curricula, built with Electron and TypeScript.

## Features

- [ ] Create and manage educational curricula
- [ ] Organize content by subjects and topics
- [ ] Track progress and completion
- [ ] Export/import curriculum data

## Prerequisites

- Node.js (v16 or later)
- npm (v7 or later) or Yarn

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/curricula.git
   cd curricula
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Build the application:
   ```bash
   npm run build
   ```

5. Start the application:
   ```bash
   npm start
   ```

## Project Structure

- `src/` - Main process TypeScript files
- `renderer/` - Renderer process files (HTML, CSS, JavaScript)
- `dist/` - Compiled JavaScript files (created after build)

## Scripts

- `npm run dev` - Start in development mode with hot-reload
- `npm run build` - Compile TypeScript to JavaScript
- `npm start` - Start the application
- `npm test` - Run tests (to be implemented)
